לוח הבקרה של אפי

כל מה שצריך כדי להוסיף תוכן לאתר – במחשב, לא בטלפון

לוחצים על מה שרוצים לעשות, וקוראים את שלושת הצעדים. כל כפתור ירוק פותח את המסך הנכון ב-GitHub, כשהתיקייה הנכונה כבר פתוחה – אי אפשר לטעות.

ספר חדש

  1. לוחצים על הכפתור הירוק למטה. נפתח מסך של GitHub עם תיקיית books כבר פתוחה.
  2. גוררים את קובץ ה-PDF (או Word) לתוך המסגרת המקווקוות, או לוחצים choose your files ובוחרים אותו.
  3. גוללים למטה ולוחצים על הכפתור הירוק Commit changes. זהו. תוך כמה דקות הספר מופיע באתר עם שער.

תמלול חדש (קבוצות)

  1. לוחצים על הכפתור הירוק. נפתח מסך של GitHub עם תיקיית transcripts פתוחה.
  2. גוררים את הקובץ (PDF או Word) למסגרת.
  3. לוחצים Commit changes. התמלול מופיע תחת 'קבוצות ← תמלולים'.

תמונות לגלריה קיימת

  1. בוחרים למטה את הגלריה.
  2. לוחצים על הכפתור הירוק. נפתח מסך GitHub עם תיקיית הגלריה פתוחה.
  3. גוררים את התמונות (אפשר הרבה בבת אחת) ולוחצים Commit changes. התמונות מצטרפות לגלריה.

תמונות מהטלפון (גם HEIC) וסרטונים (mp4 עד 25MB) מתאימים. האתר מקטין אותן לבד.

גלריה חדשה

  1. כותבים למטה את שם הגלריה, למשל תאילנד 2025.
  2. לוחצים על 1. ליצור את הגלריה. נפתח מסך GitHub עם קובץ מוכן – רק לוחצים שם על Commit changes (הכפתור הירוק, למטה מימין).
  3. חוזרים לכאן ולוחצים על 2. להעלות תמונות. גוררים את התמונות ולוחצים Commit changes.

הוגה חדש

  1. כותבים למטה את השם בעברית ובאנגלית.
  2. לוחצים על 1. ליצור את ההוגה. נפתח מסך GitHub עם כרטיס מוכן – אפשר להוסיף שם כמה שורות ביוגרפיה, ואז Commit changes.
  3. חוזרים לכאן ולוחצים 2. להעלות קבצים – תמונה (portrait.jpg), ספרים (PDF), הקלטות (mp3).

הקלטה חדשה

  1. הקלטות של פגישות הן קבצים גדולים, ולכן הן עולות ל-ארכיב האינטרנט (archive.org) ולא לאתר.
  2. לוחצים על הכפתור, נכנסים לחשבון efipaz@gmail.com, ומעלים את קובץ ה-mp3 עם כותרת (למשל: פגישות בודהיזם בנהריה 2026).
  3. האתר מושך את רשימת ההקלטות מהארכיב לבד – פעם בשבוע, או בכל עדכון אחר של האתר.

מה קרה עם מה שהעליתי?

  1. אחרי Commit changes האתר מתעדכן לבד תוך 2–5 דקות. כאן רואים את המצב.
  2. אם כתוב ❌ – לשלוח לאריה את הקישור של העמוד הזה.

לראות את העדכונים ב-GitHub

שלוש הערות

  • במחשב בלבד. מסך ההעלאה של GitHub לא עובד טוב בטלפון.
  • קובץ גדול מ-25MB (סרטון ארוך) לא עובר דרך הדפדפן – לשלוח לאריה.
  • סבלנות: אחרי Commit changes לוקח 2–5 דקות עד שהאתר מתעדכן. אפשר לבדוק ב"מה קרה עם מה שהעליתי?".
